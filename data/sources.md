# Data Sources

This project integrates publicly available operational, financial, workforce, sustainability, and industry datasets to support the executive decision dashboard. The original source documents are **not** included in this repository to maintain a lightweight repository and to respect the distribution policies of the original publishers.

The processed datasets required to reproduce the dashboard are included in this repository. All original reports remain publicly accessible through their official publishers.

---

# Source Document Policy

To keep this repository concise, reproducible, and focused on the analytical workflow, original corporate reports, investor presentations, and sustainability reports are **not redistributed**.

Readers can access the latest official versions directly from the organisations listed above.

Only the processed datasets, dashboard, report, and supporting analytical artefacts developed as part of this project are included in this repository.
